Análisis de Ventas de Walmart

Este trabajo analiza los datos de ventas de Walmart para identificar factores que influyen en el rendimiento de las tiendas.

Objetivos: - Identificar variables importantes para las ventas - Analizar el impacto de promociones - Evaluar diferencias por tipo de tienda - Examinar patrones estacionales

Datos utilizados: - train.csv: ventas semanales por tienda - features.csv: variables externas (temperatura, promociones, etc.) - stores.csv: información de tiendas

Hallazgos principales:

  1. Las promociones tienen efecto positivo en las ventas
  2. La temperatura influye en el comportamiento de compra
  3. Hay diferencias significativas por tipo de tienda
  4. Los días festivos afectan las ventas

Recomendaciones:

  • Ajustar inventario según estación del año
  • Aprovechar días festivos para promociones
  • Considerar tipo de tienda en metas de ventas
  • Monitorear indicadores económicos

Limitaciones:

  • Algunos datos de promociones faltantes
  • Período limitado de análisis
